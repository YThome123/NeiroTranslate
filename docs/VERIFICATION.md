## Обработка речи и ошибок

- `speech-queue.js` владеет одной активной попыткой озвучки и максимум двумя ожидающими свежими репликами. Ожидание начала очередной реплики ограничено тремя секундами после её подготовки; это не обещание общего сетевого лага до трёх секунд.
- Завершение определяется реальными источниками WebAudio / событием браузерного движка, а не завершением HTTP-загрузки. Бюджет речи учитывает длину текста и запуск сервиса, с предельной страховкой 15 секунд. Эти 15 секунд не являются задержкой между репликами: нормально завершившаяся речь освобождает очередь сразу.
- Пауза, перемотка, остановка и явная смена провайдера очищают очередь и прерывают текущую попытку. Конец короткого cue сам по себе не обрезает нормальную фразу посередине слова.
- Поиск/запуск браузерного голоса ограничены по времени, пустые/ошибочные списки обновляются. Для прерванной речи с известной позицией резервному голосу передаётся остаток; неизвестный уже произнесённый префикс не повторяется вслепую.
- Резервный Google-вызов не меняет выбранный пользователем провайдер или текущую громкость. Просроченный/отказавший fallback освобождает владельца очереди, не оставляя все следующие фразы заблокированными.
- Устаревшие чтения настроек не могут откатить новый выбор; изменения во время временно неактивного перезапуска не теряются. Следующий успешный запрос восстанавливает состояние после временной ошибки хранилища. Ошибки сохранения видны в UI, неподтверждённые изменения откатываются.
- В ходе сетевой проверки обнаружен разовый таймаут перевода первой неизменной строки. Добавлен один повтор при подтверждении от content script, что тот же текст всё ещё присутствует в текущих субтитрах той же сессии/версии. Старые, отменённые и квотные запросы не повторяются. Ошибки двух попыток остаются видимыми; бесконечного повтора нет.

Сохранённые результаты: `test-results/unit-v314.log`, `stream-voices.json`, `stream-voices-live.json`, `playback.json`, `playback-live.json` и логи `*-v314.log`. Каталог исключён из Git и ZIP. CI запускает потоковый набор с фикстурами. Основные исправления переключения/очереди прошли независимый review; найденные гонки воспроизведены падающими регрессиями и исправлены, повторная проверка этих исправлений существенных замечаний не дала.

Сетевая задержка, отсутствие CC на конкретном эфире и ограничения бесплатных API остаются возможны. Очередь теперь отдаёт приоритет цельности речи; старые измерения v3.1.3 ниже относятся к прежней более агрессивной отмене и не являются новой гарантией скорости.

## Измерение сокращения задержки

Одинаковая пятифразовая дорожка проверена в реальном Chromium с выпуском **3.1.2 из ZIP** и текущим **3.1.3**. В контрольном сравнении HTTP-задержки фиксированы: 250 мс на перевод и 450 мс на загрузку Google-аудио; само видео, декодирование и WebAudio настоящие. Результаты: 5/5 реплик в каждом прогоне, медиана от начала cue до слышимого звука **1512 → 418 мс**. Это контрольный сценарий с готовой дорожкой, а не обещание ускорения сети.

С реальными бесплатными сервисами новая готовая дорожка также воспроизвела **5/5 реплик**. Задержки от начала cue: **416, 1134, 1088, 839, 879 мс**, медиана **879 мс**. Измеряется слышимый выход аудиографа, а не только получение HTTP-ответа. Это один прогон; он не задаёт гарантированную задержку для всех сайтов и соединений.

Для фраз, впервые появляющихся без подготовки, первоначальный сетевой baseline завершился 5/5, а два последующих запуска — 4/5 из-за недоступности перевода первой реплики. Поэтому улучшение общей сетевой медианы на этом пути **не подтверждается** неполными выборками. Неудачные отчёты сохранены; они не заменены успешными цифрами готовой дорожки. У стримов без будущих субтитров всё ещё возможна заметная сетевая задержка.

Команды и файлы:

```sh
python tests/playback-e2e.py --lookahead --baseline --release dist/neirotranslate-3.1.2.zip
python tests/playback-e2e.py --lookahead
```

## Покрытие

- Пауза во время запроса перевода/синтеза и уже звучащей речи: отмена запросов, отбрасывание поздних ответов, остановка источников WebAudio, нулевой измеренный звуковой выход.
- Перемотка во время запроса/речи и на паузе: старая реплика отменяется, новая берётся из позиции назначения.
- «Стоп», повторный запуск, обновление страницы, смена скорости и конец видео: старые фразы не возвращаются, громкость восстанавливается.
- Ответы не по порядку, просроченные ответы, зависший синтез, быстрые смены реплик: новая фраза не ждёт старую и не накапливает очередь.
- Длинный cue остаётся видимым после семи секунд; короткий очищает текст и звук по своему сроку. Проверяется класс видимости, а не только наличие текста.
- Буферизация сохраняется до `playing`, включая несколько опросов состояния.
- Отказ Google → голос браузера; восстановление Google отменяет браузерную реплику. При отсутствии обоих голосов показывается ошибка, перевод текста сохраняется.
- Модульные проверки дополнительно покрывают восстановление фонового процесса, устаревшие резервные голоса, поздние события движка, таймауты, квоты, кэш и микшер Gemini.

В сценариях отказа браузерного голоса заменяется граница `chrome.tts`: headless Chromium не предоставляет все системные голоса пользователя. Декодирование, планирование и остановка Google-аудио проверяются на настоящем WebAudio. Датчик добавляется только во временную копию и не входит в ZIP.

## Измерения и реальная задержка

Последний прогон с фикстурами: перевод после начала HTTP-запроса — **5 мс**, пауза → тишина — **62 мс**, новая озвучка после зависшей предыдущей — **109 мс**. Для быстрых cue остаток запланированного звука составил **0,258 с**, без очереди старых фраз.

Последний сетевой прогон: первый перевод — **394 мс**, запрос TTS → измеренный звук — **2429 мс**, пауза → тишина — **110 мс**. Это отдельные замеры, не среднее и не гарантия задержки. Сетевая озвучка может стартовать через несколько секунд. Исправления отменяют устаревшее содержимое и не дают отставанию накапливаться.

До исправления повторный сетевой тест дал **5 ошибок из 15**: лимит 1200 мс отбрасывал доступные, но медленные сервисы. Теперь резервные запросы стартуют через 600 мс, запросу даётся 1800 мс, всему переводу — 2400 мс; победитель отменяет остальные запросы. Итоговый прогон — **15/15**: первичный сервис ответил за **1468 мс**, принудительные резервные пути — за **939 мс** через MyMemory и **716 мс** через второй Google-хост.

Ожидание перевода отделено от срока показа cue: длинная готовая строка не обрывается через 2,5 секунды. Без известных таймингов используется короткий срок актуальности; просроченные реплики пропускаются, длинная речь может сокращаться ради синхронизации. Доступность сервисов зависит от сети, региона и квот.

## Воспроизведение и отчёты

Команды приведены в таблице; перед браузерными тестами нужны `pip install -r requirements-dev.txt`, `python -m playwright install chromium`, `python tools/make-demo-media.py`. Генерация видео требует FFmpeg.

- `test-results/playback.json`, `playback-live.json`: каждый сценарий, длительность, версия браузера, измерения и диагностика ошибок.
- `test-results/playback-fixtures.log`, `playback-live.log`, `ui-fixtures.log`, `ui-live.log`, `unit-tests.log`: полный вывод наборов.
- `test-results/free-providers-hedged.log`: успешный итоговый сетевой прогон; `free-providers.log` сохраняет предыдущий неудачный прогон.

`test-results/` исключён из Git и поставки. CI сохраняет отчёт с фикстурами отдельным артефактом. `python tools/package.py` собирает `dist/neirotranslate-3.1.2.zip`; файлы архива сверены с исходниками, тестовые датчики и ключи в него не входят. Скриншоты сняты с расширения на демонстрационном видео; статистика на них демонстрационная.

Не проверены успешные платные запросы Gemini/ElevenLabs/SpeechKit с ключами владельца, все сайты/ОС/браузеры, каждый системный голос и многосуточные стримы. Последняя сетевая проверка Gemini с неверным ключом получила `gemini_timeout`: проверена обработка сбоя подключения, но отклонение ключа именно в этом прогоне не подтверждено. С фикстурой проверяется ответ `gemini_bad_key`.

Бесплатный режим требует доступных субтитров и не распознаёт речь из видео без CC. GitHub Actions настроен, но удалённый запуск из этой рабочей папки не выполнялся.
