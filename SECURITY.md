# Ключи и сообщения о проблемах

NeiroTranslate не поставляется с личными API-ключами. Пользователь вводит свои значения в настройках расширения; они хранятся в `chrome.storage.local` текущего браузера, не синхронизируются и не входят в экспорт истории.

## Перед публикацией

```sh
node tools/check-secrets.mjs --history
```

Проверка распознаёт распространённые форматы ключей ElevenLabs, Google, GitHub и приватных ключей. Она проверяет содержимое и имена публичных файлов и, с указанным флагом, объекты Git, включая недостижимые и старые имена файлов. Значения совпадений не печатаются. Сборка проверяет точный набор входных файлов ZIP, в том числе игнорируемые Git ассеты; отсутствующий входной файл останавливает сборку.

В старой истории сохранён явно фальшивый токен из исходного E2E-теста. Исключение ограничено его точным SHA256 и действует только для истории; текущие файлы не могут использовать это исключение. Реальные пользовательские ключи в проект и историю не добавлялись.

Не коммитьте `.env`, локальные учётные данные, профили браузера и результаты проверки личного аккаунта. Кэши, `test-results/` и `dist/` исключены из Git. Перед публикацией изображений проверяйте, что на них нет открытых полей ключей или персональных данных.

## Если ключ попал в чат, лог или репозиторий

Отзовите или перевыпустите его в панели провайдера. Удаление строки из текущего файла не отзывает ключ и не удаляет прошлые коммиты. Если секрет был в Git, очистите историю перед публикацией и повторите проверку. Само расширение не отзывает ключи вашего аккаунта.

В публичном issue достаточно указать версию, браузер, режим и текст ошибки без ключа. Не публикуйте скриншот открытого поля API-ключа, весь профиль браузера или аудио с личными данными.
